For the standard put one down/ pick one up game styles, I want to have the shared card at the top and the user's card at the bottom.
I want users to be able to play with people remotely as well as in person, so they can share the link to add other players to game. Users play on their own phones.
Players can also play by themselves against a timer.
We could make it harder by having more symbols per card. But we do not need to have the whole deck (remove the card count check), as eg. if there 12 symbols per card there would have to be 133 cards in the deck which is just insane. We could cap it at 57 cards for a fun game.
The user tabs the symbol in common - if they tap more than one incorrectly when answering the user cannot claim that card. More than 5 incorrect taps in a game means they forfeit. 
Let's use emojis right now, but not face ones- they should be ones that users can quickly identify and are commonly used objects.
At a later stage, allow choose from library.
